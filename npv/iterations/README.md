# NPV 迭代来回文档（`iterations/`）

本目录专门用于留存**外部任务布置（Gemini）**与**内网执行总结（codeagent）**之间的来回迭代文档，与 GitHub 仓库 `Mint-Artist/miaomiao`（分支 `agent/npv-page-value-score`，路径 `npv/iterations/`）保持同步。

## 命名与协作约定

- **任务布置（外部 → 内网）**：`gemini_<序号>_<主题>.md`
  - 例如：`gemini_01_标注口径核查与300对复测.md`
  - 包含背景、硬性红线、可执行步骤、验收门禁与回传模板。
- **执行总结（内网 → 外部）**：`codeagent_<序号>_<主题>.md`
  - 例如：`codeagent_01_标注口径核查与300对复测.md`
  - 严格对应同序号的任务书，按模板填报统计结果、抽查样例与异常项。
- **公开仓库脱敏红线**：由于同步仓库为公开仓库，所有文档仅保留方法、Prompt、统计口径与公开/脱敏页面示例，**严禁写入内网地址、密钥、内部表名路径或未脱敏业务数据**。

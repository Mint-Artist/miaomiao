## 0. 概览

| 方法 | 输入 | 一句话 | 离线评测 |
|---|---|---|---|
| `md_struct_secmerge_t512` | markdown | 摊平成段落 / 列表项 / 表格行，按 256 字装箱，相邻小节合并，表格按 512 字装箱 | **已评测，hit@3000字 最好** |
| `html_struct_secmerge_t512` | html | 同上，输入换成 html | 已评测 |
| `md_struct_secmerge_t512_adh` | markdown | 上上行 + 标题吸附（块尾悬空的编号小标题挪到下一块） | **未评测** |
| `html_struct_secmerge_t512_adh` | html | 同上，输入换成 html | **未评测** |
| `html_container` | html | 以完整的结构容器（列表、表格、提示框…）为单位，≤ 1024 字整块保留 | 已评测 |

关系：

```
markdown ─ Markdown 解析 ─┐
                          ├─ 结构单元(Atom) ─ 小节打包(吸附=否) ─ 小节合并 ─ 过滤 → *_t512
html ───── html 扁平解析 ─┘                 └ 小节打包(吸附=是) ─ 小节合并 ─ 过滤 → *_t512_adh
html ───── html 容器解析 ─ 容器单元(Unit) ─ 容器装块（含吸附、容器前文）─ 块合并 ─ 过滤 → html_container
```

## 1. 通用约定

1. **字数 = Unicode 码点数**（Python `len`）。emoji、生僻字（如 😀、𠀀）算 1 个字。Java 不能用 `String.length()`。
2. **空白 = Python `str.isspace()` 的 29 个字符**：`\t \n \x0B \f \r \x1C–\x1F 空格 \x85 \xA0(NBSP)    –          　`。所有"去首尾空白""是否为空"都用这个集合。
3. **正则**：Python 的 `\s` = 上面的空白集合；`\d` = Unicode 十进制数字（`\p{Nd}`，含全角 `１`）；`$` 只在串尾或串尾的 `\n` 前匹配；`.` 不匹配 `\n`。
4. **最终过滤**：去掉"不计换行字数 < `MIN_LEN`(20)"的块。
5. **块内分隔**：块由若干行用 `\n` 拼接。

### 参数

| 参数 | 默认 | 用于 |
|---|---|---|
| `SOFT` | 256 | 段落装箱上限；小节 / 块合并上限 |
| `HARD` | 512 | t512 系列：单个单元 ≤ HARD 不拆 |
| `MIN_LEN` | 20 | 最终过滤；吸附时"剩余不足"的判断 |
| `TABLE_SOFT` | 512 | t512 系列：表格行装箱上限 |
| 伪标题最大字数 | 40 | 整段加粗短行视为伪标题的上限 |
| `ADH_MAX_LEN` | 40 | 类标题行最大字数 |
| `ADH_MAX_LINES` | 4 | 吸附最多挪几行 |
| `ADH_LEAD_IN` | False | 不带编号的冒号引导句是否算类标题行 |
| `CT_HARD` | 1024 | 容器级：容器整块保留上限；段落不拆上限；吸附后长度上限 |
| `CT_SPLIT` | 512 | 容器级：超大容器 / 超长段落拆分后的块目标长度 |
| `CT_TINY` | 20 | 容器级：小于它的容器按段落处理 |
| `CT_HEAD_MAX` | 100 | 容器级：超过它的 h 标签按段落处理 |
| `CT_LEAD` / `CT_LEAD_MAX` / `CT_LEAD_KINDS` | True / 256 / table, list, code | 容器级：容器前文 |
| `NOTE_CLASSES` / `META_CLASSES` | note / metadata | 容器级：提示框 / 元信息的 div class |

## 2. 文本工具

### 2.1 正则（原文）

| 名称 | Python 原文 |
|---|---|
| `WS` | `[ \t\r\f\v\xa0　]+` |
| `SENT_END` | `[。！？!?；;…]+[”’"）)】》」』]*\|\n+` |
| `END_PUNCT` | `[。！？!?；;，,、…]$` |
| `MD_HEADING` | `^(#{1,6})\s+(.*?)\s*#*\s*$` |
| `MD_LIST` | `^\s*(?:[-*+]\|\d{1,3}[.)])\s+(.*)$` |
| `MD_PIPE_SEP` | `^\s*\|?\s*:?-{2,}:?\s*(\|\s*:?-{2,}:?\s*)*\|?\s*$` |
| `MD_IMAGE` | `!\[([^\]]*)\]\([^)]*\)` |
| `MD_LINK` | `\[([^\]]*)\]\([^)]*\)` |
| `MD_EMPH` | `(\*\*\|__)(.+?)\1` |
| `MD_BOLD_LINE` | `^\s*(\*\*\|__)(.+?)\1\s*$` |
| `HTML_TAG` | `<[^>]+>` |
| br | `<br\s*/?>`（忽略大小写） |

（表中 `\|` 是 Markdown 表格转义，正则里是 `|`。）

### 2.2 函数

- **clean_inline(s)**：按 `\n` 分行（保留空行位置）；每行把 `WS` 连续空白替换成一个空格，再去首尾空白；丢掉空行；用 `\n` 拼回。
- **split_sentences(text, max_len)**：
  1. 用 `SENT_END` 从左到右找匹配，每个匹配的结束位置切一刀（句末标点及其后的引号 / 括号留在前一句；连续换行留在前一句）；剩余部分作为最后一句。
  2. 对每一句：长度 > `max_len` 时，在前 `max_len` 个字里找**最后一个** `，` `,` `、`；位置 > 0 则切在它后面，否则硬切 `max_len` 字；重复直到 ≤ `max_len`。剩余部分非空白才保留。
- **split_long(text, soft)**：对 `split_sentences(text, soft)` 贪心拼接：当前段非空且加上下一句超过 `soft` 字就另起一段；最后各段去首尾空白、丢掉空段。
- **is_pseudo_heading(t)**：`0 < 字数 ≤ 40` 且 `END_PUNCT` 不匹配（末尾不是标点）。
- **md_inline(s)**：依次 br→`\n`；图片→`\1`（alt 文字）；链接→`\1`；强调→`\2`；删除所有 `<...>`；最后 `clean_inline`。

## 3. Markdown 解析 → Atom

Atom：`kind`（heading / para / li / row / code）、`text`、`level`（heading 用，1–7）、`table_id`、`header`（row 用）。

把 `\r\n` 换成 `\n` 后按 `\n` 分行，`i` 从 0 开始；`s = 去首尾空白(行)`。逐行按以下**顺序**判断：

1. `s` 为空 → 跳过。
2. `s` 小写后以 `<table` 开头 → HTML 表格：从当前行起收集，直到某行小写后包含 `</table>`（或到最后一行）；把收集的行用 `\n` 拼起来按 html 解析（**不**替换 br），文档中**每个** `<table>`（含嵌套）按 §4.3 取行和表头，每行生成 `row(text, table_id, header)`；每张表 `table_id += 1`。
3. `s` 以 ` ``` ` 开头 → 代码块：收集之后的原始行，直到某行去首尾空白后以 ` ``` ` 开头（该行不收）；收集内容拼接后非空白则生成 `code("\n".join(行))`。
4. `s` 以 `|` 开头且下一行匹配 `MD_PIPE_SEP` → 管道表格：表头 = `s` 去掉两端 `|` 后按 `|` 分割、各格去空白、用 ` | ` 拼接；跳过分隔行；之后每个"去空白后以 `|` 开头"的行：去空白、去两端 `|`、按 `|` 分割、各格 `md_inline`、用 ` | ` 拼接，生成 `row(行, table_id, md_inline(表头))`；`table_id += 1`。
5. `s` 匹配 `MD_HEADING` → `t = md_inline(组2)`，非空则 `heading(t, level = # 的个数)`。
6. `s` 匹配 `MD_BOLD_LINE` 且 `is_pseudo_heading(md_inline(组2))` → `heading(md_inline(组2), 7)`。
7. **原始行**（未去空白）匹配 `MD_LIST` → `t = md_inline(组1)`，非空则 `li(t)`。
8. 否则 `t = md_inline(s)`，非空则 `para(t)`。

注：Markdown 里没有段落合并——**每个非空行都是一个单元**。

## 4. html 扁平解析 → Atom（t512 / _adh 用）

### 4.1 预处理
- 用 lxml 解析（Java 用 jsoup，差异见《Python与Java差异对照.md》）。
- 所有 `<br>` 替换为文字 `\n`。
- 跳过的标签 `SKIP`：script、style、noscript、template、svg、iframe、head、title、meta、link。
- 行内标签 `INLINE`：a、abbr、b、big、cite、code、em、font、i、img、label、mark、q、s、small、span、strike、strong、sub、sup、time、u、br、del、ins。

### 4.2 遍历
维护文字缓冲 `buf`。**flush**：`t = clean_inline(buf 拼接)`，清空 buf，`t` 非空则生成 `para(t)`。

从文档根开始遍历子节点（深度 0）：
- **字符串节点**（文字、注释、doctype 等，见差异文档）→ 原文追加到 `buf`；
- **元素**（不在 SKIP 中）→ 按下表处理：

| 元素 | 处理 |
|---|---|
| 深度 > 200 | `get_text()` 追加到 buf |
| h1–h6 | flush；`t = clean_inline(get_text())`，非空则 `heading(t, 级别)` |
| p | flush；`t = clean_inline(get_text())`；若 p 去掉纯空白字符串后**只有一个子节点且是 strong / b**，且 `is_pseudo_heading(t)` → `heading(t, 7)`；否则 `t` 非空 → `para(t)` |
| ul / ol | flush；对每个**直属** li：`t = own_text(li)`，非空则 `li(t)`；再对该 li 的**直属** ul / ol 递归处理（深度 + 1） |
| table | flush；按 §4.3 取行和表头，每行 `row(行, table_id, 表头)`；`table_id += 1` |
| pre | flush；`t = get_text()`，非空白则 `code(t 去掉首尾 \n)` |
| INLINE | `get_text()` 追加到 buf |
| 其他（div、section、blockquote…） | flush；遍历其子节点（深度 + 1）；flush |

遍历结束再 flush 一次。

- `own_text(li)`：li 的直属字符串节点原文 + 直属元素（ul、ol、table、SKIP 除外）的 `get_text()`，拼接后 `clean_inline`。
- `get_text()`：所有后代**普通文字**拼接（不含注释；不含 rt / rp / script / style / template 里的文字，见差异文档）。

### 4.3 表格行（两种解析共用）
对表格的每个 `tr`（**最近的 table 祖先是本表**，即嵌套表格的行不算）：
- 单元格 = tr 的**直属** td / th；每格 `clean_inline(get_text("\n"))` 再把 `\n` 换成空格；
- 全部单元格为空 → 跳过；
- 行文本 = 单元格用 ` | ` 拼接；
- **表头**：该 tr 有 thead 祖先，或直属单元格全是 th；并且此前还没有数据行、也还没有表头 → 作为表头；否则作为数据行。

## 5. 小节打包（t512 与 _adh 共用，吸附开关区分）

输入 Atom 列表，输出记录 `(文本, 上级标题路径, 是否以标题开头)`。

状态：当前块 `cur`（若干行）、每行的类标题信息 `cur_tl`、当前类型族 `cur_family`、当前块的 `cur_parent` / `cur_head`；标题栈 `path`（(级别, 序号)）；待吸附标题 `pending`（(序号, 文字)）。
**flush**：`cur` 非空则输出 `("\n".join(cur), cur_parent, cur_head)`；清空 `cur`、`cur_tl`，`cur_family = 空`。

对第 `i` 个 Atom `a`：

1. **标题**：flush；弹出 `path` 末尾所有级别 ≥ `a.level` 的项，压入 `(a.level, i)`；`pending` 追加 `(i, a.text)`；继续下一个。
2. 否则：
   - 类型族 `family`：row → `("row", table_id)`；li → `("li")`；其他（para、code）→ `("text")`。
   - 上限 `lim` = row 用 `TABLE_SOFT`，其他用 `SOFT`。
   - `whole = 字数(a.text) ≤ HARD`；片段 `pieces = whole ? [a.text] : split_long(a.text, lim)`。
   - 对每个片段 `piece`：
     1. `piece_tl` = （a 是 para 且 whole）? 类标题信息(piece)（§9）: 空。
     2. `size = cur 各行字数之和 + 行数`。
     3. **需要切断**：`cur` 非空，且（`family ≠ cur_family` 或 `size + 字数(piece) > lim`）：
        - 吸附关闭（t512）：flush。
        - 吸附开启（_adh）：计算 `k` = `cur_tl` 末尾连续非空的个数，然后依次：
          - `k > ADH_MAX_LINES` → `k = 0`；
          - 末尾这 `k` 行里同一编号样式出现 ≥ 2 次 → `k = 0`；
          - `k > 0` 且 `piece_tl` 是编号标题且 `cur_tl` 最后一行也是编号标题 → `k = 0`；
          - `k > 0`：`moved` =（`cur` 前 `len-k` 行字数和 < MIN_LEN）? 整个 `cur` : 末尾 `k` 行；若 `Σ(字数(moved 每行)+1) + 表头长度(row 且有表头时为 字数(header)+1，否则 0) + 字数(piece) > HARD` → `k = 0`。
          - `k > 0`：若 `cur` 前 `len-k` 行字数和 < MIN_LEN → `carry = 整个 cur`，`inherit = (cur_parent, cur_head)`，清空 `cur`（**不输出**）；否则 `carry = 末尾 k 行`，从 `cur` 去掉它们后 flush。
          - `k = 0` → flush。
     4. `add = piece`。若 `cur` 为空（新块开始）：
        - row 且有表头 → `add = header + "\n" + add`（**每个表格块都带表头**）；
        - `cur_parent` = `path` 中序号**不在** `pending` 里的那些序号（按栈顺序）；`cur_head = pending 非空`；
        - `pending` 非空 → `add = pending 文字用 \n 拼接 + "\n" + add`（标题与紧随的第一段同块）；
        - `carry` 非空 → `add = carry 用 \n 拼接 + "\n" + add`（吸附过来的行放最前，表格块里在表头之前）；若有 `inherit` 则 `(cur_parent, cur_head) = inherit`；
        - `cur_family = family`；清空 `pending`。
     5. `cur` 追加 `add`，`cur_tl` 追加 `piece_tl`。
3. 全部处理完：若 `pending` 非空（页面以标题结尾），按 4 中规则算 `cur_parent`，`cur_head = 真`，`cur` 追加 pending 文字；最后 flush。

**吸附关闭时结果与 t512 原版逐字一致**（已用随机测试验证），所以只需实现一个打包器。

## 6. 小节合并（merge_sections，target = SOFT）

按顺序处理打包记录 `(text, parent, head)`，维护输出组 `(文本, scope)`：
- 若已有组 `g`，且 `parent` 以 `g.scope` 为前缀（`parent[:len(scope)] == scope`），且 `字数(g.文本) + 1 + 字数(text) ≤ target` → `g.文本 += "\n" + text`；
- 否则新开一组：`scope = head ? parent : parent 去掉最后一项`。

含义：后一块只能并入"同一上级标题之下"的前一组；以标题开头的块的范围是它的上级路径，否则是去掉最近一级。

## 7. 方法 1–4

```
md_struct_secmerge_t512        = 过滤(合并(打包(Markdown解析(markdown), 吸附=否)))

```
过滤：去掉不计换行字数 < MIN_LEN 的块。

## 8. 方法 5：html_container

### 8.1 容器解析 → Unit
Unit：`kind`（heading / para / list / table / note / metadata / quote / code / figure）、`items`（para、heading 只有 1 条）、`level`、`header`、`caption`。

**block_text(el)**：遍历子节点——字符串节点原文追加到当前行；非 SKIP 元素若是块级（p、div、section、article、main、aside、header、footer、nav、li、ul、ol、h1–h6、blockquote、pre、figure、figcaption、table、thead、tbody、tfoot、tr、caption、dl、dt、dd、details、summary、hr）则前后各另起一行并递归，否则直接递归；最后各行用 `\n` 拼接后 `clean_inline`。
`lines_of(el)` = `block_text(el)` 按 `\n` 分行、去掉空行。

**排版表格**：没有表头，且每个本表 tr 的直属 td / th 中"`clean_inline(get_text())` 非空白"的单元格最多 1 个。

预处理（br→`\n`、SKIP、INLINE）与 §4.1 相同；遍历与 flush 同 §4.2（flush 生成 `para`），元素处理：

| 元素 | 处理 |
|---|---|
| 深度 > 200 | `get_text()` 追加到 buf |
| h1–h6 | flush；`t = block_text`；`字数(t) > CT_HEAD_MAX` → `para(t)`；否则非空 → `heading(t, 级别)` |
| p | flush；`t = block_text`；只有一个 strong / b 子节点且伪标题 → `heading(t, 7)`；否则非空 → `para(t)` |
| ul / ol | flush；有直属 li → 每个 li 的 `block_text`（非空）为一项；否则 `lines_of`；有项 → `list` |
| table | flush；按 §4.3 取行和表头；caption = 第一个后代 caption 的 `clean_inline(get_text())`（`\n` 换空格）；**排版表格** → 每个本表 tr 的 `block_text` 非空则生成 `para`；否则有行或表头 → `table(行, header, caption)` |
| pre | flush；`t = get_text()` 去掉首尾 `\n`，非空白 → `code(t 按 \n 分行)` |
| blockquote / figure | flush；`lines_of` 非空 → `quote` / `figure` |
| div 且 class 含 note / metadata | flush；`lines_of` 非空 → `metadata`（含 metadata class 时）否则 `note` |
| INLINE | `get_text()` 追加到 buf |
| 其他 | flush；遍历子节点（深度 + 1）；flush |

### 8.2 装块
状态：标题栈 `path`、待吸附标题 `pending`；**段落块** `run`（若干行）及每行的类标题信息 `run_tl`、描述段字数 `run_desc`（完整段落记字数，否则空）、`run` 的 `(parent, head)`；输出记录 `recs`：`(文本, parent, head, kind, 可合并)`。

- **take_pending**：返回（pending 文字列表、parent = path 中不在 pending 里的序号、head = pending 非空），清空 pending。
- **flush_run**：`run` 非空则输出 `("\n".join(run), run 的 parent, run 的 head, "para", 可合并=是)`；清空 run 及附属列表。
- **trailing_k**：`run_tl` 末尾连续非空个数 `k`；`k > ADH_MAX_LINES` 或同一样式 ≥ 2 次 → 0。
- **tail_fits(k, extra)**：`whole` = run 前 `len-k` 行字数和 < MIN_LEN；`moved` = whole ? 整个 run : 末尾 k 行；`Σ(字数+1) + extra ≤ CT_HARD`。
- **take_tail(k, extra)**：不满足 tail_fits → 返回（空、无）；否则取走 moved（whole 时整个 run 清空，并返回 inherit = run 的 (parent, head)）。

按顺序处理 Unit：

1. **heading**：flush_run；更新 path；pending 追加 `(序号, 文字)`。
2. **para**：`t` 字数 ≤ CT_HARD → `add_para(t, 类标题信息(t), 描述字数 = 字数(t))`；否则对 `split_long(t, CT_SPLIT)` 的每片 `add_para(片, 空, 空)`。
3. **极小容器**（items 字数和 + header + caption < CT_TINY）→ `add_para(caption、header、items 用 \n 拼接, 空, 空)`。
4. **其他容器** → `emit_container(u)`。

最后 flush_run；pending 非空则输出 `(pending 文字, parent, 真, "para", 可合并=是)`。

**add_para(piece, tl, desc)**：
- run 非空且 `run 字数和 + 行数 + 字数(piece) > SOFT`：`k = trailing_k`；若 `k > 0` 且 tl 是编号标题且 run 最后一行也是 → `k = 0`；`k > 0` → `carry, inherit = take_tail(k, 字数(piece))`；然后 flush_run。
- run 为空：`take_pending`；run 的 (parent, head) = inherit 或 take_pending 的结果；run 追加 `pending 文字 + carry + [piece]` 用 `\n` 拼接。否则 run 追加 piece。
- run_tl 追加 tl，run_desc 追加 desc。

**emit_container(u)**：
1. `k = trailing_k`；`body_len` = 字数(caption、header、items 用 \n 拼接)。
2. **容器前文**：CT_LEAD 且 `u.kind ∈ CT_LEAD_KINDS` 且 `body_len ≤ CT_HARD`：`j = len(run) - k - 1`；若 `j ≥ 0` 且 `run_desc[j]` 非空且 ≤ CT_LEAD_MAX 且 `run_tl[j]` 为空，且 `tail_fits(k+1, body_len)` → `lead, inherit = take_tail(k+1, body_len)`。
3. lead 仍为空且 `k > 0` → `extra = body_len ≤ CT_HARD ? body_len : 字数(header)+字数(caption)+2+字数(items[0])`；`lead, inherit = take_tail(k, extra)`。
4. flush_run；`take_pending` 得到 (pre, parent, head)；有 inherit 则用 inherit 的 (parent, head)。
5. `first = pre + lead + [caption（非空时）]`；`rep = table 且有 header ? [header] : []`。
6. `whole = "\n".join(first + rep + items)`；字数 ≤ CT_HARD → 输出 `(whole, parent, head, kind, 可合并=是)`。
7. 否则拆分：`pieces` = 每个 item（> CT_SPLIT 的先 `split_long(item, CT_SPLIT)`）；`cur = first + rep`，`has = 否`，`n = 0`；对每个 p：若 `has` 且 `cur 字数和 + 行数 + 字数(p) > CT_SPLIT` → 输出 `("\n".join(cur), parent, head 且 n==0, kind, 可合并=否)`，`n += 1`，`cur = rep`（**续块重复表头**），`has = 否`；`cur` 追加 p，`has = 是`。结束时 `has` 或 `n == 0` → 输出最后一块（可合并 = `n == 0`）。

### 8.3 块合并（SOFT）
按顺序处理 recs，维护输出组（文本、scope、kind、含容器、可合并）：
- 已有组 `g`，且：本记录可合并、`g` 可合并、**不是"g 已含容器且本记录也是容器"**、`parent` 以 `g.scope` 为前缀、`字数(g) + 1 + 字数(text) ≤ SOFT` → 并入（`\n` 连接）；本记录是容器时 `g.含容器 = 真`、`g.kind = 本记录 kind`。
- 否则新开一组：`scope = head ? parent : parent 去掉最后一项`，`含容器 = kind ≠ para`。

最后过滤字数 < MIN_LEN 的组。块类型 = 组的 kind。

## 9. 类标题行识别（_adh 与 html_container 共用）

**编号样式**（按顺序取第一个匹配，匹配对象是去首尾空白后的文字开头）：

| 样式 | 正则（Python 原文） |
|---|---|
| 数字 | `^\d{1,2}(?:[、)）]\|[.．](?!\d))` |
| 括号数字 | `^[（(]\d{1,2}[)）]` |
| 中文数字 | `^[一二三四五六七八九十]{1,3}[、.．]` |
| 括号中文数字 | `^[（(][一二三四五六七八九十]{1,3}[)）]` |
| 第X | `^第[一二三四五六七八九十百零\d]{1,3}[章节部分条步篇讲课]` |
| 圈号 | `^[①-⑳]`（U+2460–U+2473） |
| 步骤 | `^(?:step\|步骤)\s*\d{1,2}`（忽略大小写） |

**title_like(text)**：`t` = 去首尾空白；空或字数 > ADH_MAX_LEN → 否；末字是 `：` 或 `:` → 有编号样式则"编号标题"，否则 ADH_LEAD_IN ? "引导句" : 否；末字属于 `。！？!?；;，,、…` → 否；有编号样式 → "编号标题"，否则否。
**类标题信息** = （类型，编号样式；引导句没有样式）。

## 10. 边界情况

| 情况 | 结果 |
|---|---|
| 输入为空 / 只有空白 | 空列表 |
| 页面以标题结尾 | 标题单独成块（再参与合并） |
| 单元超过上限且无标点 | 按上限硬切 |
| 标签没闭合 | 由解析器修复，Python（lxml）与 Java（jsoup）可能不同，见差异文档 |
| doctype、注释、`<?xml?>` | 作为字符串节点进入正文（Python 原版行为，Java 已复刻，见差异文档） |
| 极深嵌套（> 200 层） | 该层以下直接取文字 |
